# Copy img to root img directory and edit path in html

Copy img to root img directory and edit path in html

## Usage

``` r
copy_img_and_edit_path(html_path, img_root_dir)
```

## Arguments

- html_path:

  character. Path to html file.

- img_root_dir:

  character. Path to img root dir

## Value

None. Side effet : edit img path in html.
